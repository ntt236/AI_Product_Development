# Business Modules Directory

Theo kiến trúc trong `docs/architecture/PROJECT_STRUCTURE.md`:
Thư mục này chứa các module nghiệp vụ theo từng domain (Domain-Oriented).

Trong **Phase 0 (Foundation)**, không tạo trước các file rỗng hoặc mã giả định.
Các module sẽ được triển khai theo từng vertical slice hoàn chỉnh ở các giai đoạn tiếp theo:
- **Phase 1**: `auth`, `onboarding`, `learner-profile`
- **Phase 2**: `assessment`
- **Phase 3**: `learning-path`
- **Phase 4**: `daily-plan`, `content`, `practice`
- **Phase 5**: `tutor`, `ai`
- **Phase 6**: `vocabulary`
